# 🗺 Developer Roadmap: BirthdayBot v1.1

Этот план составлен на основе финальной спецификации v1.1. Следуйте фазам последовательно.

## Фаза 1: Инфраструктура и БД (Cloudflare)
- [ ] Инициализировать Cloudflare Worker (`wrangler init`).
- [ ] Создать базу данных Cloudflare D1 (`wrangler d1 create birthday_db`).
- [ ] Применить миграции (схемы таблиц `users`, `birthdays`, `templates`, `send_log`).
- [ ] Настроить переменные окружения и Secrets (BOT_TOKEN, OPENROUTER_KEY, INTERNAL_TOKEN).

## Фаза 2: Слой MTProto (Hetzner VPS)
- [ ] Поднять Python FastAPI сервер на Hetzner.
- [ ] Реализовать авторизацию через Telethon (`phone` -> `send_code` -> `verify_code`).
- [ ] **Безопасность**: Реализовать шифрование `session_string` ключом AES-256, который запрашивается у Workers.
- [ ] Настроить эндпоинт `/send` для приема команд на отправку сообщений.

## Фаза 3: AI Генератор (OpenRouter)
- [ ] Интегрировать OpenRouter API (модель Llama 3.1 8B).
- [ ] Реализовать функцию `generateGreeting(relationType, friendName)`:
    - Тон на основе типа отношений.
    - Ограничение 1-3 предложения.
- [ ] Реализовать **Fallback**: если ИИ вернул ошибку, переключиться на Gemma 2 или системный шаблон.

## Фаза 4: Авто-режим (Push Interception)
- [ ] В Python-сервисе реализовать фоновый слушатель `events.NewMessage`.
- [ ] Настроить фильтр на сообщения от сервисного аккаунта Telegram про дни рождения.
- [ ] При событии:
    1. Извлечь имя контакта.
    2. Проверить в D1, не было ли отправки сегодня.
    3. Запустить цепочку генерации и отправки.

## Фаза 5: Фронтенд (Telegram Mini App)
- [ ] Создать React приложение с `@tma.js/sdk`.
- [ ] **Экран Добавления**:
    - Реализовать выбор `relation_type` (4 кнопки: друг, коллега, знакомый, родственник).
    - Добавить вкладку AI с кнопками «Сгенерировать», «Ещё вариант» и «Использовать».
- [ ] **Экран Настроек**: Удалить поле «Мой стиль», оставить только тоггл авто-режима.

## Фаза 6: Cron и Запуск
- [ ] Настроить Cron Trigger в Cloudflare Workers (каждые 30 мин).
- [ ] Логика крона: выборка из `birthdays` по времени MSK и отправка через Hetzner.
- [ ] Финальное тестирование на 2-3 аккаунтах.
