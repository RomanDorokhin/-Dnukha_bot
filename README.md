# 🎂 BirthdayBot (Днюха) — v1.1.0

Умный Telegram-бот для автоматизации поздравлений. Умеет ловить системные уведомления Telegram о днях рождения друзей и поздравлять их с помощью AI, либо работать по вашему списку расписания.

## ✨ Ключевые фичи

- **🤖 Auto-Mode**: Перехват системных пушей. Если Telegram присылает вам уведомление «У Ивана сегодня день рождения», бот тут же генерирует поздравление и отправляет его.
- **✨ AI-Driven**: Использует **Llama 3.1 8B** (OpenRouter) для написания уникальных текстов. Никаких «счастья-здоровья», только живой и уместный текст.
- **🎭 Тональность**: 4 режима отношений (Друг, Коллега, Знакомый, Родственник) — бот меняет стиль текста под каждого.
- **🛡 Безопасность (Split-Key)**: Ваши сессии Telegram зашифрованы AES-256-GCM. Мастер-ключ хранится в Cloudflare Secrets, а данные — на вашем VPS. Мы физически не можем прочитать ваши чаты без ключа из памяти.
- **📱 Mini App**: Современный интерфейс на React прямо внутри Telegram.

## 🏗 Архитектура

- **Frontend**: React + Vite + TMA SDK.
- **Backend (API & Logic)**: Cloudflare Workers + Hono + D1 (SQLite).
- **MTProto Layer**: Python + Telethon + FastAPI (на Hetzner/VPS).

## 📁 Структура папок

- `/client` — Исходники React приложения (Vite).
- `/server` — Cloudflare Worker (TypeScript, SQL миграции).
- `/mtproto` — Python сервис для работы с протоколом Telegram.

## 📝 Ограничения (MVP)

- Лимит 10 генераций поздравлений в час.
- Лимит 10 отправок сообщений в сутки на пользователя (защита от спама).
- Анти-дубль: бот не поздравит одного и того же человека дважды в один год.
